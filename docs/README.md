## Быстро: самое важное

- **Выпуск — строго по порядку:** `make_release.ps1` → запушить только `dist/` → выпуск на GitHub с тегом `X.Y.Z` (без `v`) и **двумя** файлами из `release\` → проверить → только потом запушить `update.json`. [Подробно](release.md).
- **В выпуск — только `release\NeonCenterline.gms`** (без заголовка CorelDRAW 2026), не файл из `%APPDATA%`: иначе старые плагины напишут «контрольная сумма не совпала». [Почему](pitfalls.md#повреждён-контрольная-сумма-не-совпала-при-любом-обновлении--заголовок-gms-coreldraw-2026).
- **Не править сгенерированное:** строки — `tools/strings.py`, ядра — `core/`, панель — `addon/`. [Карта](development.md#карта-репозитория).
- **Перед сборкой** — `shadow_check.py`, `call_check.py`, `lo_compile.py`; условия с индексом — вложенными `If`. [Почему](pitfalls.md#vba).
- **Не трогать:** название панели «Неон (NeonCenterline)» и имена линий «Неон: центр N» — по ним плагин находит свою панель и свои линии. [Почему](pitfalls.md#имя-линий-и-имя-панели--это-идентификаторы).
