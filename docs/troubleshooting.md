# Если что-то не работает

Для пользователей и для того, кто помогает пользователю. Сначала — самое частое: панель, обновление, сообщения инструментов. Описание кнопок — в [README](../README.md).

Макросы запускаются так: **Инструменты → Макросы → Запуск макроса** (в новых версиях пункт может называться «Скрипты»), в списке выбрать проект `NeonCenterline`, затем модуль и макрос — например `NeonUI` → `ResetToolbar`. Ниже такие макросы записаны полным именем: `NeonCenterline.NeonUI.ResetToolbar`.

## Сначала — какая версия стоит

«Настройки и помощь ▾» → **О программе**: версия плагина. Если вопрос про то, что уже исправлено, — сначала обновиться («Проверить обновления») или поставить свежий архив с [Releases](https://github.com/ShiZa039/NeonCenterline/releases).

## Панель

| Что видно | Что делать |
|---|---|
| Панели «Неон (NeonCenterline)» нет | Окно → Панели инструментов → «Неон (NeonCenterline)». Нет в списке — файлы панели не легли в Addons (не дали права администратора): запустить макрос `NeonCenterline.NeonAddon.InstallToolbar`, подтвердить права, **полностью** перезапустить CorelDRAW. Не помогло — скопировать папку `addon\NeonCenterline` из архива в `C:\Program Files\Corel\CorelDRAW Graphics Suite <версия>\Programs64\Addons\` вручную (см. README, «Ручная установка»). |
| Кнопки пустые, без значков или подписей | Старые CorelDRAW (X7–X8) панель дополнений могут не показать. Кнопки можно поставить вручную: Инструменты → Настройка (Ctrl+J) → Команды → «Макросы», перетащить нужные `NeonCenterline.…` на любую панель; значки — в папке `icons` архива. |
| После обновления плагина на панели старые кнопки | Плагин сам предлагает обновить панель один раз — если тогда ответили «Нет»: макрос `NeonCenterline.NeonUI.ResetToolbar`. Он либо сбросит панель к новому набору, либо скажет, что файлы панели в Addons старые, и предложит их обновить (права администратора, потом перезапуск CorelDRAW). |
| `ResetToolbar` пишет «не удалось сбросить» | В его отчёте — какие панели найдены, файлы панели в Addons (метка набора `[NeonToolbar N]`, `Resources<N>.dll` с размером и датой) и какой набор ждёт плагин. Если метки не совпадают — `InstallToolbar`, перезапуск. Отчёт пригодится автору. |
| Хочется вернуть панель как после установки | Макрос `NeonCenterline.NeonUI.ResetToolbar`: сбрасывает только панель «Неон», остальное рабочее пространство не трогается. |

## Макросы не запускаются совсем

- В CorelDRAW должен быть установлен компонент **VBA** (Visual Basic for Applications) — он ставится установщиком CorelDRAW и может быть не выбран. Без него ни один плагин GMS не работает: изменить установку CorelDRAW («Программы и компоненты» → CorelDRAW → Изменить) и добавить VBA.
- Плагин должен лежать в папке GMS **той** версии CorelDRAW, которая запущена: `%APPDATA%\Corel\CorelDRAW Graphics Suite <версия>\Draw\GMS\NeonCenterline.gms`. `install.cmd` ставит в самую новую версию; для другой — скопировать вручную.
- «Модуль «…» не найден в проекте плагина. Переустановите плагин.» — файл плагина неполный или старый: поставить заново из архива (CorelDRAW закрыт).

## Обновление

Как оно работает: раз в сутки (после расчёта центральных линий) или по кнопке «Проверить обновления» плагин читает `update.json` с GitHub, при новой версии спрашивает, скачивает файл во временную папку, проверяет, что это файл плагина и что контрольная сумма совпала, и запускает маленький скрипт: тот ждёт, пока CorelDRAW закроется, сохраняет старый файл как `NeonCenterline.gms.bak` и кладёт новый. Новая версия — со следующего запуска.

| Сообщение | Что значит | Что делать |
|---|---|---|
| «Не удалось проверить обновления: HTTP …» / «…таймаут…» + про блокировку GitHub | Ни один из трёх адресов не ответил: нет сети, прокси, GitHub закрыт у провайдера. Бывает и `HTTP 404` при скачивании, если автор опубликовал `update.json` раньше файлов. | Попробовать позже или скачать архив с Releases вручную и поставить `install.cmd`. |
| «Скачанный файл обновления не подошёл: это не файл плагина (сеть подменила или оборвала загрузку)» | Пришла страница прокси, обрезанный файл — или (у плагинов до 1.1.2) файл CorelDRAW 2026 с заголовком, который старая проверка не понимала. | Поставить новую версию из архива; дальше обновления пойдут сами. |
| «…контрольная сумма не совпала (ждали …, пришло …)» | Скачанный файл не тот, что описан в `update.json`: оборванная загрузка или ошибка выпуска. | Повторить позже; повторяется — поставить из архива и сообщить автору (с текстом сообщения). |
| «…не удалось посчитать контрольную сумму (certutil и PowerShell недоступны)» | Политика компьютера запрещает обе программы. | Ставить новые версии из архива. |
| «Не найден файл плагина (.gms) для замены.» | Плагин загружен не из файла `NeonCenterline.gms` (переименован?). | Поставить из архива под стандартным именем. |
| «Обновление X уже скачано и установится после закрытия CorelDRAW.» | Всё в порядке, скрипт ждёт закрытия. | Закрыть CorelDRAW **полностью** (в Диспетчере задач не должно остаться `CorelDRW.exe`). |

**Закрыл CorelDRAW, а версия старая.**
- CorelDRAW ещё работает в фоне (`CorelDRW.exe` в Диспетчере задач) — скрипт ждёт до суток. Завершить процесс или перезагрузиться: при следующей проверке плагин сам запустит скрипт снова, не скачивая заново.
- Антивирус или политика запретили `wscript.exe` — поставить из архива.

**Откатиться на прошлую версию.** Закрыть CorelDRAW, в папке GMS удалить `NeonCenterline.gms` и переименовать `NeonCenterline.gms.bak` в `NeonCenterline.gms`. Или поставить архив нужной версии с Releases. Отключить ежедневную проверку — в Настройках.

**С 1.0.x после обновления** на вопрос про панель ответить «Да», подтвердить права администратора и полностью перезапустить CorelDRAW.

## Сообщения инструментов

| Инструмент | Сообщение | Что делать |
|---|---|---|
| Все | «Ничего не выделено», «Выделите…» | Выделить объекты; группы и текст подходят, кроме оговорённого ниже. |
| Все | «Отменить не удалось» после «Отмена» в отчёте | Отменить обычным Ctrl+Z. |
| Люверсы | «…нет замкнутого контура (подпутей: N, замкнутых: M; концы не сходятся)» | Концы контура расходятся больше чем на 0.5 мм: соединить узлы (или «Замкнуть кривую»). |
| Люверсы | «люверсы не помещаются с таким отступом от края» | Отступ от края слишком большой для этого объекта — уменьшить отступ. |
| Люверсы | «Внутри баннера … — без люверсов: N» | Так и задумано: люверсы — только по внешнему краю. Нужны на внутреннем объекте — выделить его отдельно. |
| Раскладка | «Ни одна деталь не помещается на лист с такими полями» / «Больше рабочего поля листа» | Деталь больше листа минус поля — увеличить лист, уменьшить поле, разрешить поворот. |
| Раскладка | Деталь встала внутрь другой, где не надо | Снять галочку «Детали внутрь других (матрёшкой)». Контур детали должен быть замкнутым. |
| Одинаковые | «Не удалось сгруппировать наборов: N (объекты на разных слоях?)» | Перенести объекты на один слой. |
| Упростить | «В выделении нет кривых» | Текст и фигуры — сначала в кривые (Ctrl+Q). |
| Очистить | Прямоугольники и эллипсы пропущены | Так и задумано — в них нет наложений. Отдельные объекты, которые надо слить, — сначала объединить (Ctrl+L). |
| Центральные линии | «Нет замкнутых контуров» | Выделить контуры букв (кривые, текст, группы), а не линии. |
| Центральные линии | Мелкий текст с маленькой фрезой: дуги ломаные («0» с угловатым боком), у «3» средние дуги сходятся углом | Допуск сглаживания был 0,25 мм — почти половина штриха буквы 5–6 мм. Исправлено в 1.1.3 (допуск — не грубее 1/16 штриха): обновиться. |
| Центральные линии | «Фреза велика для этих букв…»; концы линий не доходят, острия «А» и «М» не сходятся, на мелком тексте линии пропали | Конец линии ставится на D/2 от края (с фрезой 8 мм — 4 мм). Для мелкого текста и гравировки: в окне перед расчётом диаметр фрезы = диаметр гравера, или «Отступ конца линии от края» 0–0,3 мм. Подгонка по кратности тут ни при чём. |

**Окно хода работы долго не закрывается.** Счётчик секунд идёт — плагин работает: раскладка по контуру на сотнях деталей и больших листах может идти минуты. Отмены расчёта нет. Если счётчик стоит и CorelDRAW «Не отвечает» долго — завершить CorelDRAW через Диспетчер задач (несохранённое пропадёт) и прислать автору файл.

## Сбросить все настройки плагина

Закрыть CorelDRAW и удалить в реестре ключ `HKEY_CURRENT_USER\Software\VB and VBA Program Settings\NeonCenterline` (Win+R → `regedit`). Плагин вернётся к значениям по умолчанию; файлы не трогаются. Что где хранится — [architecture.md](architecture.md#настройки-в-реестре).

## Как сообщить о проблеме

[Issues на GitHub](https://github.com/ShiZa039/NeonCenterline/issues) или автору напрямую:
1. версия плагина («О программе») и версия CorelDRAW;
2. снимок сообщения целиком (или текст);
3. файл, на котором воспроизводится (CDR или SVG; можно только нужные объекты);
4. для панели — отчёт `ResetToolbar`; для обновления — текст сообщения.
