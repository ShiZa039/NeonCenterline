## Что нового в 1.1.2

### Обновление из плагина

- **Обновление из плагина снова работает.** Проверка «скачан настоящий файл плагина» не понимала заголовок `.gms` из CorelDRAW 2026 и отбраковывала любое обновление как «повреждённое (контрольная сумма не совпала)». Теперь заголовок учитывается; если файл не подошёл, пробуется запасной адрес, а в сообщении сказано, почему не подошёл.
- 1.1.2 должна прийти сама и к тем, у кого стоит 1.0.x–1.1.1: файл плагина в этом выпуске — без того заголовка, и старая проверка его пропускает.

### Люверсы

- **Контур под подгиб** — галочка и выпуск (по умолчанию 50 мм): линия реза, отнесённая наружу от края баннера (у прямоугольника — прямоугольник с острыми углами). Люверсы по-прежнему отсчитываются от края баннера.
- **Только край баннера:** у группы «баннер + рисунок» люверсы больше не ставятся на рисунок, текст и рамки внутри — только на внешний контур.
- **Контуры, нарисованные линиями** без замыкания или собранные из отрезков, теперь считаются замкнутыми, если концы сходятся, — люверсы на них ставятся.

## Установка и обновление

**Инструкция по установке — в [README](https://github.com/ShiZa039/NeonCenterline#%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0)**. Коротко:

- **Уже стоит 1.0.x или 1.1.x:** плагин сам предложит обновление (проверяет раз в сутки после расчёта) или «Настройки и помощь ▾» → «Проверить обновления»; новая версия встанет, когда вы закроете CorelDRAW. С 1.0.x после обновления на вопрос про панель ответьте «Да», подтвердите права администратора и полностью перезапустите CorelDRAW. Если обновление из плагина всё же не проходит — поставьте из архива (ниже), дальше обновления пойдут сами.
- **Новая установка:** скачайте `NeonCenterline-1.1.2.zip` (ниже, в «Assets»), распакуйте, закройте CorelDRAW и запустите `install.cmd`.

## What's new in 1.1.2

### Updating from the plugin

- **Updating from the plugin works again.** The "a real plugin file was downloaded" check did not understand the header of a CorelDRAW 2026 `.gms` and rejected every update as "damaged (checksum mismatch)". The header is now accepted; if a file does not pass, the backup address is tried, and the message says why it did not pass.
- 1.1.2 should also reach those on 1.0.x–1.1.1 by itself: the plugin file in this release comes without that header, so the old check accepts it.

### Grommets

- **Hem outline** — a box and the allowance (50 mm by default): a cut line offset outward from the banner edge (a rectangle gets a sharp-cornered rectangle). Grommets are still measured from the banner edge.
- **Banner edge only:** with a "banner + artwork" group, grommets are no longer placed on the artwork, text and frames inside — only on the outer outline.
- **Outlines drawn with lines** and not closed, or assembled from segments, now count as closed if their ends meet — grommets are placed on them.

## Install and update

**Installation instructions are in the [README](https://github.com/ShiZa039/NeonCenterline#installation)**. In short:

- **Already on 1.0.x or 1.1.x:** the plugin offers the update itself (it checks once a day after a run), or Settings and help ▾ → "Check for updates"; the new version is installed when you close CorelDRAW. Coming from 1.0.x, answer "Yes" to the toolbar question, confirm administrator rights and fully restart CorelDRAW. If the update from the plugin still does not go through, install from the archive (below) — later updates will then come by themselves.
- **New installation:** download `NeonCenterline-1.1.2.zip` (below, under "Assets"), unzip it, close CorelDRAW and run `install.cmd`.

Full list of changes: [CHANGELOG.md](https://github.com/ShiZa039/NeonCenterline/blob/main/CHANGELOG.md); every button is described in the [README](https://github.com/ShiZa039/NeonCenterline#readme).
